# eCampus для Android

Мобильный клиент на Rust для Android 8 и выше. Интерфейс, навигация, календарь и обработка учебных данных написаны на Rust и собираются в WebAssembly. Android WebView отображает экраны и выполняет HTTPS-запросы к eCampus с общей cookie-сессией. Нужен актуальный Android System WebView с поддержкой WebAssembly и модулей JavaScript.

## Установка

Установите `build/eCampus-debug.apk` на телефон или выполните из этой папки:

```sh
adb install -r build/eCampus-debug.apk
```

Для входа укажите логин и пароль, нажмите «Войти», решите пример с картинки и снова нажмите «Войти». Кнопка «Деморежим» открывает автономный пример с вымышленным профилем. Выход из профиля очищает данные студента и cookies приложения.

## Экраны

- **Главная** показывает профиль, среднее по числовым оценкам текущего семестра, пропуски и занятия на сегодня. После входа профиль загружает страницу `/details` в текущей сессии. Из активной записи `viewModel.EducationDetails` берутся полное ФИО, курс, код и название направления. Группа берётся из профиля расписания. Если подробные сведения недоступны, используются данные расписания, учебной истории и имя из шапки кабинета. Для каждой активной образовательной программы приложение берёт её ID с учебной страницы, запрашивает занятия по каждому типу предмета и считает общее среднее по всем выставленным числовым оценкам. Каждая запись с Attendance = 0 даёт один пропуск. Во время подсчёта виден прогресс. При сбое можно повторить недостающие запросы прямо из профиля.
- **Расписание** позволяет переключать дни и недели. Лупа открывает выбор института, специальности и группы. Кнопка слева возвращает к личному расписанию на сегодня. Чётность рассчитывается от недели, содержащей 1 сентября.
- **Предметы** показывает курсы и семестры из академической истории. Нажатие на предмет открывает оценки и посещаемость по его типам занятий.
- **Сервисы** содержит оценки и список пропусков за выбранный семестр. В списке и карточке предмета показываются только занятия с `Attendance = 0`. Остальные девять пунктов, включая карту корпусов и уведомления, показывают локальную заглушку «Сервис пока недоступен».

Данные загружаются прямо с `https://ecampus.ncfu.ru` по контрактам из `CampusBOT/ECAMPUS_API_USAGE.md`. Пароль используется при входе. Предметы, расписание и оценки хранятся в памяти до выхода или завершения процесса. При повторном запуске клиент проверяет сохранённую сессию на портале.

## Сборка

Понадобятся Rust и Cargo с целью `wasm32-unknown-unknown`, JDK 17 или 21, Android SDK Platform 36, Build Tools 35.0.0 и утилита zip. На Linux из папки клиента:

```sh
rustup target add wasm32-unknown-unknown
export ANDROID_HOME="$HOME/Android/Sdk"
cargo test
./scripts/build-apk.sh
```

Скрипт проверяет подпись APK и выводит путь к файлу. Для локальных сборок он создаёт отладочный ключ в `build/debug.keystore`. Отладочная сборка предназначена для установки напрямую на устройство.

## Просмотр деморежима в браузере

После сборки запустите `python3 -m http.server 8080 --bind 127.0.0.1 --directory build/assets` и откройте `http://127.0.0.1:8080/`. Авторизация с порталом работает в Android-приложении. Для работы деморежима доступ к сети университета не требуется.
